# Steal An Egg — pattern card
**Category:** high social chaos / collection. **The current #1 game on the platform.**

**Observed (API, 2026-10-17):** 3,579,638 playing · 8.49B visits · server size 7 · created **2026-07-25** · 92% like · 2 passes (×2 Money 399, ×2 Growth 467). Tracker peak about 11.07M (2026-09-26, Unverified).

**Evidence:**
- Observed: official description and passes.
- Unverified guides: biomes, speed gates, mutations.
- Tizzy's post-mortem of a derivative game (video note).

## 1. Audience, fantasy, promise
- Audience: young players chasing a viral trend.
- Fantasy: daring raids into dangerous zones to grab eggs.
- Promise: "Steal eggs, hatch rare pets, get faster, steal from players."

## 2. Player experience by time (Inferred)
- **15 s:** spawn next to your base and the first biome. An egg is visible past a guardian.
- **60 s:** first steal run and carry-back. The egg is **auto-equipped**, according to Tizzy's analysis of this game's onboarding.
- **5 min:** hatch, first pet earns money, train on the treadmill for speed.
- **30 min:** next biome speed gate, mutations, first player-vs-player steal.

## 3. Loops
- **Core:** sprint into a biome → grab the egg → escape the guardian → return.
- **Meta:** speed stat gates biomes, rarer eggs, mutations, fusion.
- **Social:** steal eggs from other players' bases.
- **Event:** updates and new biomes.
- **Return tomorrow:** eggs growing and incubating (a "Grow All" meter), speed goals.

## 4. Economy
- Cash from pets. Speed is the gating stat (a treadmill sink).
- Mutation multipliers: about 5 types, with one top mutation at about 2.5% (Unverified).
- Fusion carries a risk of losing a mutation, which acts as a sink.

## 5. UI map
- A right-side "Growing Eggs" menu and a shop with passes (Unverified guides).
- Speed requirement shown per biome. This is a clear "next goal" display.

## 6. Motion and feedback
- Chase and escape tension against the guardian, size/mutation reveals at hatch, and the treadmill speed-up.
- **The run is the clippable unit.**

## 7. Social
- Theft between players.
- 7-player servers.
- Console support is declared in the description, so the game targets console parity.

## 8. Monetization
- Only 2 permanent multiplier passes (Observed).
- Most revenue is presumably from developer products: speed tiers, instant hatch, limited items (Inferred from Tizzy's description of the genre's monetization).

## 9. Live-ops
- Frequent biome and egg additions (Inferred).
- Spawned many clones: Break and Steal an Egg (#17), "Steal a Egg".

## 10. Friction and risks
- Peak-trend dependency. Already about 67% off its tracker peak in 3 weeks.
- Theft distress.
- Exploit scripts are widely advertised.
- A derivative (Raise an Anomaly) died within about a month.

## 11. Transferable vs. protected
- **Transferable:**
  - **stat gate shown on the world itself** ("need X speed")
  - auto-equip of newly gained items
  - a run → return → invest rhythm
  - console parity
- **Protected:** the "Steal a ___" title, the egg and pet raid theme, guardian design, layout.
- **Reject as a genre** (saturation).
- **Our alternative:** keep the *short dangerous run plus safe-zone return* rhythm, inside an original co-op or skill fantasy with no player-vs-player theft.
