## Gap list (all must ship)
G1 Media viewer: full-screen lightbox for any image (Review, chat, pitches, corpus): zoom in (+ or scroll), zoom out (-), fit (0), download, previous/next (arrow keys), close (Esc).
G2 Review depth: Reject asks for a reason; Hold with a reason (parked, not rejected); "Looks good, with this note" and "Not right: say what" free-text verdicts; reference-only items ("nothing to decide here"); "Reject all" and "Empty the queue without approving anything" bulk actions (each with confirm); "How it reads small" preview showing an image at 150 px and 512 px next to full size; a **Visual bar** tab: owner pins approved images as house references by category (Packaging, UI icons, 3D models, Screens) and every designer/thumbnails/ui brief lists them ("the house reference for every hand-off").
G3 Publish gate: a separate "Publish gate" screen/modal for the irreversible, human-only acts (make a version live, set the experience public, spend ad money). Two-step confirm: step 1 opens the confirmation (does nothing), step 2 requires typing the game slug to enable the button; pointer click only, never batched. Ad money is advisory only (records the owner's note, no control). Shows a human-only checklist (things the repo cannot verify: played on a phone, checked the store page, read the monetization policy). Below a divider: reversible review decisions.
G4 Stage requests: Reject with reason and Hold with reason; optional failed-criteria ids (Producer rubric, e.g. `G5 S4`, pattern `^[A-Z][0-9]{1,2}$`); `reworkCount` ("times sent back for rework") on games and tasks; a "Kicked back" list (rejected requests, context only).
G5 "Back to you": a finished task (state review, not a gate) shows "What was asked", the result, and **Looks good** / **Needs changes: say what**. Looks good -> done; Needs changes -> queues a rework task for the same role with the note and attempt + 1.
G6 Chats: Start fresh archives the conversation; "Past chats" list per role to read old ones ("Back to the current chat"); Ctrl+Enter also sends; a note that a new message "waits until the agent finishes". Ask cards in chat accept an option or "Or say it in your own words…".
G7 Shell: Ctrl+N opens New task; the palette also searches conversations (message text); loading state "Reading the studio…".
G8 Home: "Pick the next game -> See the pitches" card when no game is in progress or pitches await; "Ready to publish · only you can -> Open the publish gate" card when a game is at stage ready.
G9 Pitches: game-type taxonomy for `format` (Collect & upgrade, Steal & escape, Survive & extract, Build & defend, Find the hidden, Race & rank, Tycoon & expand, Guess & reveal, Clean & restore, Raise & evolve) shown as the type chip and offered in the editor; "Send to Scout" (request changes) label; Closest competitors with "Their gap:"; tiles "Money (top earning)" and "Growth (upvotes/day)"; "Custom systems to build" and "Biggest risk" rows; a banner when a pitch fails the schema ("can't be decided; Scout has to fix it"); New idea form gets "Anything else (optional)".
G10 Market: corpus thumbnails actually load (fix the thumbnails fetch: use `https://thumbnails.roblox.com/v1/games/multiget/thumbnails?universeIds=<ids>&countPerUniverse=3&defaults=true&size=768x432&format=Png&isCircular=false`); **title analysis** over charting titles (sample size, share verb-article-noun, verb-initial without article, with emoji or symbol, word count and title length distribution, common first words); column help text for breakouts (players now, peak 7 d, lifetime visits, age days, players per 1K visits = young and pushed, growth since first seen); the server refreshes market data automatically every `marketEveryHours` (setting, default 6; 0 = off) so velocity and breakouts keep moving.
G11 Library: "Copy the Roblox asset id" button on assets with an id; systems search box.
G12 Games > Live numbers: the full telemetry board fed by the game (see "Live telemetry"): live strip (playing now, servers, slowest server, worst ping, peak 24 h, joins 24 h, joins last hour, leaves last hour, first-minute bounce, Robux last hour, errors last hour, versions running); daily tiles (players at fetch, visits, like ratio, D1, D7, avg session, paying players) with sources and targets; charts (daily active users new/returning; players online peak per hour 3 days; Robux spent per hour by product 3 days; first-session length; session time new/returning; playtime per daily user; D1 by source; plays by source; play-through; payer conversion; spend per paying player; performance fps and crash rate; country; language; device); "Where players leave" (last place before leaving, tutorial step when they left, first-session length, where the latest session ended); "Fix ledger" (liveops attention items and the fixes that answered them). Empty states: "Private, so nothing is measurable yet", "No data yet. Daily numbers arrive after the game reports them."

## Live telemetry (shared interface)
- Game side (exec-2): pure module `src/shared/LiveStats.luau` (`--!strict`, tests in `tests/LiveStats.spec.luau`) that folds events into an aggregate: `new()`, `join(agg, {userId, isNew, source, device, country, language, version})`, `leave(agg, {userId, sessionSeconds, lastPlace, tutorialStep})`, `robux(agg, {product, amount, userId})`, `error(agg, {message})`, `perf(agg, {fps, crashed})`, `snapshot(agg, now) -> table` (counts and histograms only; no user ids in the output). Server service `src/server/Services/StatsService.luau` wires Players.PlayerAdded/Removing, the existing Telemetry funnel step for tutorial progress, MarketplaceService receipts (read-only hook from the existing receipt path, never granting), ScriptContext.Error, and every 60 s writes `snapshot` to DataStore `HQStats` under key `live` and merges into `day-YYYY-MM-DD` (UpdateAsync, pcall, budget-aware). Tuning values in `src/shared/Config/Tuning.luau` (interval, max error samples). Studio/unpublished: DataStore calls fail silently. Update `docs/technical-architecture.md` (new service, data shape, privacy: aggregates only).
- HQ side (exec-1): owner-only setting `openCloud` = `{apiKey, universeId}` stored in `.agent-hq/opencloud.json` (mode 0o600, never returned by any route; `/api/state` shows only `{configured: bool}`). Fetcher `fetchLiveStats` (injectable) GETs `https://apis.roblox.com/datastores/v1/universes/{universeId}/standard-datastores/datastore/entries/entry?datastoreName=HQStats&entryKey=live` and `...entryKey=day-YYYY-MM-DD` for the last 14 days with header `x-api-key`. Stores raw snapshots in `game_stats(game, key, at, json)`. `GET /api/games/:slug/live` returns `{latest, series, metrics, targets, attention, live: <latest live snapshot or null>, days: [...]}` and computes the derived metrics (D1, D7, avg session, paying share, bounce) from the day aggregates via exec-2's `liveStatsView(days, live)`. Refresh every 15 minutes when configured, plus `POST /api/games/:slug/live/refresh`.

## Other shared interfaces (exec-1 implements, exec-3/exec-4 call)
- `POST /api/asks/:id/answer` accepts `reject:<reason>`, `hold:<reason>`, `approve:<note>`, `changes:<text>`; ask gains `verdictNote`. `POST /api/asks/reject-all {ids, reason}`; `POST /api/asks/empty {ids}` (dismiss without verdict). Ask kind `reference` (no decision).
- References: `GET /api/references` -> `[{id, mediaPath, category, note, createdAt}]`; `POST /api/references {mediaPath, category, note?}`; `DELETE /api/references/:id`. Categories: packaging, ui-icons, 3d-models, screens. Briefs for designer, thumbnails and ui list them (exec-2).
- Publish gate: `POST /api/games/:slug/gate/start {action: "live"|"public"}` -> `{challengeId, expiresAt}` (2 minutes); `POST /api/games/:slug/gate/confirm {challengeId, typed}` where typed must equal the slug -> applies (live: stage live; public: sets `isPublic` flag and `publicSinceUtc`). `POST /api/games/:slug/ad-note {note}` stores advisory notes. `GET /api/games/:slug/gate` -> checklist items `{id, label, done}`; `POST .../gate/checklist {id, done}`. All owner-only. HQ never calls Roblox to publish.
- Stage requests: `POST /api/stage-requests/:id/decide {state: approved|rejected|held, reason?, criteriaFailed?: [ids]}`; rejected increments `reworkCount` on the game; `GET /api/stage-requests?state=rejected` for "Kicked back".
- Back to you: `POST /api/tasks/:id/verdict {verdict: "approve"|"changes", note?}` (owner only, task in review and not a gate).
- Past chats: `POST /api/messages/:role/reset` archives (`archive` id on messages); `GET /api/threads/:role/archives` -> `[{id, startedAt, endedAt, count, preview}]`; `GET /api/messages?role=&archive=<id>`.
- Settings: `marketEveryHours` (0..48), `openCloud` (special: write-only).
