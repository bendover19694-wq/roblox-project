## Shared interfaces

### Games, pipeline, stage requests (exec-1)
- Table `games(slug PK, name, stage, version INT, versionType, note, nextStep, universeId, changelog JSON {heading, bullets[]}, updatedAt)`. Seed `space-agency` / "Run a Space Agency" / stage `built` / version 1 / nextStep "Owner hands-on test and the phone layout pass" if missing. Stages in order: `pitched, designed, assets, built, balanced, art, ready, live, graded`; owning role per stage: scout, architect, librarian, builder+ui, economy, thumbnails, builder, owner, liveops.
- `GET /api/games` -> games with `openTasks`, `working` (role ids), `todos` (open asks of kind try/decision for that game). `POST /api/games {slug,name}`; `PATCH /api/games/:slug {name?, nextStep?, note?, universeId?, version?, changelog?}`.
- Stage requests: table `stage_requests(id, game, fromStage, toStage, role, evidence, state open|approved|rejected, createdAt, decidedAt)`. `POST /api/games/:slug/stage-requests {toStage, evidence}` (only the next stage; `live` cannot be requested by agents); `POST /api/stage-requests/:id/decide {state}`; approving moves the game and posts a system message to the Lead thread. Owner-only `POST /api/games/:slug/mark-live` (the owner published it themselves). `GET /api/stage-requests?state=`.
- Live numbers: `POST /api/games/:slug/live/refresh` -> if universeId set, GET `https://games.roblox.com/v1/games?universeIds=<id>` and `https://games.roblox.com/v1/games/votes?universeIds=<id>`, store a row in `game_snapshots(game, at, playing, visits, favorites, up, down)`. `GET /api/games/:slug/live` -> `{latest, series:[...last 30 days], metrics:{likeRatio, d1, d7, avgSessionMin, payingPct, firstMinute}, targets, attention:[...]}`; metrics not derivable publicly come from `game_metrics(game, key, value, date, source)` set by `POST /api/games/:slug/metrics {key, value, date?}` (owner or liveops), else null = "not measured". `attention` = open asks created by liveops for that game.
- Settings: `ownerName` (string ≤ 40), `studioLanes` (0 = off, 1, 2, or "all"); the claim logic allows up to studioLanes concurrent needsStudio tasks ("all" = no limit, 0 = needsStudio tasks never claimed). `/api/state.studio` becomes `{lanes, locks:[{taskId, role, game, since, lane}]}` (keep `holder` = first lock's taskId for compatibility).
- `GET /api/freshness` -> `{marketCharts, breakouts, liveNumbers, assetLibrary, games:{slug: updatedAt}}` (ISO or null).
- Uploads: `POST /api/uploads {name, mime, dataBase64}` (png/jpeg/webp only, ≤ 5 MB decoded, name sanitized) -> `{path: "uploads/<id>.<ext>"}` saved under `.agent-hq/media/uploads/`. Tasks and messages accept `attachPaths: [path]` (stored JSON); briefs list them.
- Review verdicts: review asks accept answers `approve`, `changes:<text>`, `reject`. Ask gains `verdict` (approved|changes|rejected|null) and `superseded` (true when a newer review ask exists for the same task and role). `GET /api/asks` supports `?verdict=` and `?includeSuperseded=1`. `POST /api/asks/approve-all {ids}` approves many (the "Clear the queue" action).
- Pitches (wires exec-2's `pitches.mjs`): `POST /api/pitches` accepts the full schema below; `POST /api/pitches/:id/decide {state: approved|changes|declined, note?, edits?}`; `changes` queues a scout task with the note; `approved` applies `edits` first, queues the Lead plan task, and sets other `proposed` pitches to `withdrawn`. `POST /api/pitches/ideas {title, idea}` creates a pitch `{origin:"owner", state:"evaluating"}` and queues a scout task "Evaluate owner idea: <title>".
- Market (wires exec-2's functions): `GET /api/market` -> `{latest, previous, velocity, sorts}`; `GET /api/market/corpus`, `POST /api/market/corpus {universeId}` / `DELETE /api/market/corpus/:universeId`; `GET /api/market/benchmarks`; `GET /api/market/breakouts`; `POST /api/market/refresh` also updates breakouts and records the time.
- Library (wires exec-2's `assets.mjs`): `GET /api/assets?search=&kind=&scope=` -> `{assets, counts}`; `POST /api/assets` (librarian/owner) ; `GET /api/systems` -> `{markdown}`.

### Pure modules (exec-2 writes, exec-1 imports)
- `market.mjs`: keep `fetchCharts()`; add `velocity(latest, previous)` -> `{moves:[{universeId,name,sort,rankDelta,playersDelta,playersPct}] sorted by |rankDelta|, perSort:{sortId:[rows with rank, rankDelta, playersDelta, playersPct, likePct, votes, sortsCount]}}`; `fetchGameDetails(universeIds)` (games.roblox.com/v1/games, batches of 50) -> `{universeId: {visits, created, updated, genre}}`; `computeBreakouts(snapshots, details, now)` (under 300,000 visits, over 500 playing, created within 30 days or first seen in the last 7 days; fields name, playing, peak, visits, ageDays, perThousandVisits, growth (latest/earliest playing across snapshots), likePct, genre, firstSeen); `fetchIcons(universeIds)` via `https://thumbnails.roblox.com/v1/games/icons?universeIds=..&size=150x150&format=Png` and `fetchThumbnails` via `https://thumbnails.roblox.com/v1/games/multiget/thumbnails?universeIds=..&size=768x432&format=Png`.
- `benchmarks.json`: rows `{id, benchmark, target, measuredBy, tier, failureMeaning, source}` written from this repo's research (`research/video-notes/*.md`, `research/market-snapshot.md`, `docs/game-design-document.md`), each with its source and Documented / creator-claim label. At least: first action time, first reward time, onboarding grasp, second goal time, session length, D1, D7, like ratio, play-through rate (icon/thumbnail CTR), paying share, ARPDAU, crash/error rate.
- `pitches.mjs`: `normalizePitch(input)` validating the full schema: `{title, oneLiner, format, window: early|mid|late, origin: scout|owner, edge, competitors:[{name, whatItIs, gap, universeId?}], comparables:[{name, universeId?, playing?, likeRatio?, upvotesPerDay?, rankClimb?, note?}], money:{verdict, topEarningRank?, comparable?}, saturationCount?, game:{howItPlays, first60s, goal10to15, minutes10to20, monetization, clipMoment, iconIdea, modules:[]}, evidence:{summary, links:[]}, building:{gaps:[], assetNotes, experience}, risks:[]}` (string limits 2000, arrays ≤ 20).
- `assets.mjs` + `tools/agent-hq/assets.json` (committed index `[{id, name, kind: model|icon|sound|image|thumbnail, scope: "game:space-agency"|"studio", tags:[], file, robloxId:null|string}]`): `listAssets(root, {search, kind, scope})` merges the index with unindexed files under `assets/` (kind guessed from extension, tag "unindexed"), returns counts per kind and "on Roblox" count. Seed the index with the existing files in `assets/`.
- `tools/agent-hq/systems.md` (committed): catalogue of reusable systems that exist in `src/` today (Net validators and limiter, Receipts / ProcessReceipt idempotency, ProfileSchema migrations, DataService session lock, Economy, Contracts, Launch / perfect launch, MissionClock offline catch-up, Telemetry funnel, Theme / Icons / Motion / Juice, Wizard, Toasts, Advisor): for each, what it does, where it lives, when to reuse it.
- MCP + hqctl additions: `hq_stage_request {game, toStage, evidence}` (producer and lead only, fail closed like hq_create_task), `hq_pitch` with the full schema, `hq_asset_add {name, kind, scope, tags, file}` (librarian only), `hq_metric {game, key, value, date?}` (liveops only), `hq_upload` not needed. Briefs: list `attachPaths` under "Attached images (Read them first)"; producer and lead briefs explain stage requests; scout brief requires the full pitch schema; liveops brief explains metrics and attention asks.
