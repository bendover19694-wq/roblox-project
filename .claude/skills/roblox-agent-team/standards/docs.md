# Planning and writing standard (lead, scout, architect, producer, liveops; economy and merchant when they write plans)

Read with `anti-slop.md`.

- Lead with the decision or the result. No intro, no recap, no filler.
- Every number has a source and a date; outside numbers are checked against Creator Analytics or a cited source.
- Acceptance criteria are measurable ("first upgrade inside 60 s", "D1 retention 30 percent"), never "fun" or "engaging".
- One task per role; the title says what done looks like; files are linked, never pasted.
- Plans and pitches compare against real exemplars from the reference library and name what is borrowed (structure) and what is ours (expression).
- Player-facing text is short, plain and Mild, without em dashes or emoji, readable by a 9 year old.
- If docs and code disagree, fix one in the same change.
