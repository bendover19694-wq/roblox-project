# 3D model standard (designer, librarian, world, builder when a mesh is involved)

Read with `anti-slop.md`.

## Order
1. The catalog (`hq_catalog_search`) or an asset pack, in the game's style and with a known licence.
2. Claude Design: design the model as a sheet before anyone builds it. Artifact tool, `action: "quickstart"`, `intent: "design"`: front, side, back, three-quarter and top views at one scale on a plain background, with size in studs, part list, materials and colours, triangle budget and a "leave out" list. The sheet is the spec the builder follows.
3. Blender, only when the owner turned it on in Settings, and only after 1 and 2 failed.
Primitive parts stay labelled as placeholders until they are replaced.

## Shape
- Pick a dominant shape language per asset (round is friendly, square is sturdy, triangle is danger) and one focal feature.
- Exaggerate proportions and scale contrast. Add tapers, bulges and tilts; straight parallel lines everywhere read as programmer art.
- Segment by on-screen size. Thin details flicker and vanish on phones: thicken them or drop them.
- Symmetric objects are built half plus mirror; centred features sit within 2 percent; seated parts touch.

## Surface and budget
- Colour through a palette atlas, vertex colours, or Color plus a shared texture, not a unique texture per asset.
- Check triangles, draw calls and texture memory against the phone budget for the asset's class before recommending it.
- Judge it in Studio's real lighting, never only in an editor viewport.

## Tests (attach renders)
- Silhouette (pure black on white still reads), squint, and 128 px thumbnail tests.
- Feature close-ups, not only whole-object renders.

Sources: LihFolk Vault V2 (CC BY 4.0): "Low-Poly and Stylized Modeling", "Mesh Gates for Generated Models - Symmetry, Seating and Caps", "Concept Sheets", "Art Budgets - Triangles Draw Calls Memory".
